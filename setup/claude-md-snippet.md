
## Knowledge repo (Toki-bio/knowlege)

- Before deep-reading a third-party program's source, check whether a digest skill for it already exists (skills named after the program, from the knowledge repo). Use it instead of re-reading the source.
- After any deep dive into third-party source code that took real effort, write or update a digest skill in the knowledge repo using the `digest-program-source` skill, commit, and push. Say which skill you updated.
